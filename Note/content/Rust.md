## Переменные

### Как создать переменную

```rust
let a = 123;
let b: i32 = 32132;
const c: f64 = 3213.1231;
```

### Как создать изменяемую переменную

```rust
let mut a = 123;
a = 32131;
```

### Как возвести число в степень (pow)

Надо дописать тип к литералу, или записать его в переменную с указанным типом.

```rust
2_i32.pow(8)
let a: i32 = 2;
a.pow(8);
```

### Лёгкое преобразование типа переменной в тип аргумента функции

```rust
fn abcd(n: u64, _: i32, c: u32) -> u64 {
	println!("{c}");
	return n * 2;
}

fn main() {
	let one: i32 = 1;
	let c: i8 = -3;
	let n = abcd(one as _, 3, c as _);
	
	println!("{n}")
}

```
