# neo4j

Графовая база данных.

## Запуск в докер контейнере

```bash
docker run \
    -d \
    --name neo4j \
    -p 7474:7474 \
    -p 7687:7687 \
    -v $HOME/neo4j/data:/data \
    -v $HOME/neo4j/logs:/logs \
    -v $HOME/neo4j/import:/var/lib/neo4j/import \
    -v $HOME/neo4j/plugins:/plugins \
    --env NEO4J_AUTH=neo4j/your_password \
    neo4j:latest
```

http://localhost:7474

_Разбор флагов:_

- `-d` — запустить в фоне.
- `-p 7474:7474` — порт для веб-интерфейса (Browser).
- `-p 7687:7687` — порт для подключений по протоколу Bolt (из вашего Android-приложения, например).
- `-v` — папки для хранения данных, логов, импорта и плагинов (чтобы не потерять данные при пересоздании контейнера).
- `NEO4J_AUTH=neo4j/your_password` — **обязательно поменяйте** `your_password` на свой надежный пароль.

## Как очистить индексы

### Шаг 1: Просмотр существующих индексов

```cypher
SHOW INDEXES
```

В таблице результатов обратите внимание на следующие колонки:

- `name` — имя индекса (понадобится для удаления).
- `state` — состояние (`ONLINE` работает, `FAILED` сломан, `POPULATING` создается).
- `type` — тип (например, `LOOKUP`, `BTREE`, `RANGE`, `TEXT`).
- `uniqueness` — уникальный ли он (`UNIQUE` или `NONUNIQUE`).

### Шаг 2: Удаление ненужных индексов

Чтобы удалить индекс, вам нужно использовать его имя (из колонки `name`).

**Обычный индекс:**

```cypher
DROP INDEX имя_индекса
```
_Пример:_ `DROP INDEX node_index_for_user_name`

> [!warning] ВАЖНЫЕ НЮАНСЫ (Ошибки, которые могут возникнуть)
> **1. Невозможно удалить индексы ограничений (Constraints) напрямую** Если индекс был создан автоматически вместе с ограничением уникальности (UNIQUE) или ключа узла (NODE KEY), вы не сможете удалить только индекс. Вы получите ошибку. _Решение:_ Нужно удалить само ограничение. Сначала найдите его: `SHOW CONSTRAINTS` Затем удалите: `DROP CONSTRAINT имя_ограничения`
> 
> **2. Невозможно удалить встроенный LookUp индекс** В Neo4j 5.x всегда есть системные индексы типа `LOOKUP` (обычно называются `index_343aff4e...` или похожим образом). Они обеспечивают базовую работу `MATCH (n) RETURN n`. **Удалить их нельзя**, система выдаст ошибку. Просто игнорируйте их.



## Как почистить Property Keys

Property Keys (ключи свойств) нельзя удалить вручную с помощью Cypher-команд. Их можно удалить только пересоздав базу данных.

1. Остановите и удалите текущий контейнер (данные уже сохранены на диске):
```bash
docker stop neo4j
docker rm neo4j
```    
2. Удалите папку с данными старой БД:
```bash
rm -rf ~/neo4j/data
```
3. Запустите контейнер заново:
```bash
docker run \
    -d \
    --name neo4j \
    -p 7474:7474 \
    -p 7687:7687 \
    -v $HOME/neo4j/data:/data \
    -v $HOME/neo4j/logs:/logs \
    -v $HOME/neo4j/import:/var/lib/neo4j/import \
    -v $HOME/neo4j/plugins:/plugins \
    --env NEO4J_AUTH=neo4j/your_password \
    neo4j:latest
```
