## Первый способ

1. Cкачать файл "ConferenceRoom.zip" и распаковать.
	- ![[Pasted image 20251219202914.jpg]]
2. Открыть папку с проектом и перенести распакованный ассет в папку "Content"
	- ![[Pasted image 20251219203424.jpg]]
3. Теперь он должен появится в Content Drawer. Чтобы открыть карту надо открыть файл "All/Content/ConferenceRoom/Levels/L_Showcase".
	- ![[Pasted image 20251219203740.jpg]]

Если в Content Drawer ничего не появилось есть второй способ.
## Второй способ

1. Скачать файл "Conference Project.zip"
	- ![[Pasted image 20251219203344.jpg]]
2. Распаковать и открыть файл "MyProject.uproject
	- ![[Pasted image 20251219204101.jpg]]
3. Нажать правой кнопкой мыши по папке "ConferenceRoom", нажать "Migrate" (Перенести)
	- ![[Pasted image 20251219204159.jpg]]
4. В этом окне нажать OK
	- ![[Pasted image 20251219204438.jpg]]
5. В следующем окне перейти на свой проект и выбрать папку "Content"
	- ![[Pasted image 20251219204612.jpg]]
